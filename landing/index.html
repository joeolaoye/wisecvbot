01How it works

Step 1
Message @wise_job_bot and agree to the (short, honest) privacy deal.
Step 2
Send your CV. The agent extracts a profile — you confirm it. That confirmation is the only thing matching ever reads.
Step 3
Get up to 3 alerts a day: why it fits in your terms, red flags, and the canonical apply link. Buttons tune future matches.
  • No scraping — reads the official public JSON feeds of Greenhouse, Lever, and Ashby boards
  • CVs are AES-256-GCM encrypted at rest; /delete wipes everything, verified against the database
  • Three-tier matching (rules → embeddings → LLM review) with a hard daily spend cap — a few dollars a month
  • Job postings are treated as untrusted input: injection-guarded prompts, canonical links only, plain-text messages

03Run your own

Single-tenant by design: your bot token, your database, your subscribers. Migrations apply at boot; no manual steps.

git clone https://github.com/joeolaoye/wisecvbot && cd wisecvbot
cp .env.example .env   # bot token, LLM key (OpenAI or Anthropic), CV encryption key
docker compose -f deploy/docker-compose.yml up -d --build
  • Chat + reviews run on OpenAI or Anthropic — one env var switches (LLM_PROVIDER)
  • Fully-local option: point OPENAI_BASE_URL at Ollama
  • /healthz for uptime monitors; hard daily LLM budget cap enforced in code

Full guide in docs/self-hosting.md.

04Contribute — the one-line PR

The easiest meaningful contribution in open source: add a company's job board.

# src/config/boards.yaml
- { company: Acme, ats: greenhouse, token: acme }

Verify with npm run boards:check, open the PR, done. The codebase is deliberately boring and legible — strict TypeScript, tested, one idea per module — and doubles as a learning project for engineers early in their careers. Good first issues are labeled on the tracker.
